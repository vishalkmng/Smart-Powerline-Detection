How to connect the real Arduino data

  1. Configure a ThingSpeak channel with fields: 1 Voltage, 2 Current, 3 Temperature, 4 Vibration, 5 Relay status, 6 Fault status.
  2. Use a laptop program (for example, Python or MATLAB) to read Arduino serial data and upload each reading to ThingSpeak. The Arduino Uno alone has no built-in Wi-Fi.
  3. Choose ThingSpeak channel above, enter your Channel ID and optional read key, then click Connect / Refresh. This dashboard refreshes every 15 seconds while ThingSpeak is selected.

Privacy: A public ThingSpeak channel can be read by anyone who knows its channel ID. Keep channels private and use a read key when appropriate. Never enter a write key here.

Safety

This is a monitoring dashboard, not certified protection equipment. Test with low-voltage DC only. Do not connect generic Arduino sensors directly to household 230 V AC. Relay protection should operate locally on the Arduino and must be tested with a safe low-voltage demo load.
